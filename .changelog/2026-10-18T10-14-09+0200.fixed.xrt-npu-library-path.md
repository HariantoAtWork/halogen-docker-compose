Halogen NPU failed because `halogen-npu` looks for XRT at `/opt/xilinx/lib/x86_64-linux-gnu/libxrt_core.so.2`, while the host only had libraries under `/opt/xilinx/xrt/lib`. Added Debian-style symlinks on the host and mount the full `/opt/xilinx` tree into the container so the NPU engine can load XRT.
